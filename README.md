# 2027 수시진학관리

**교사 접속:** [2027 수시진학관리 열기](https://ieum-admissions-2027-kkw.bboykw.chatgpt.site/)

학교에서 전달한 접속 비밀번호를 입력하면 전체 진학 현황을 조회할 수 있습니다. 교사 공유 조회에는 GitHub·ChatGPT 계정이 필요하지 않습니다. 생년월일·원본 자료·수정·권한 관리는 공유 접속에서 차단합니다. 관리자 입력은 별도 ChatGPT 로그인으로 보호합니다.

## 구성과 업데이트

- `hosted/`: 온라인 운영 버전의 소스, 스키마, 테스트
- `hosted-source.tar.gz`와 `hosted-source.sha256`: 학생 자료를 제외한 소스와 검증용 체크섬
- `.github/workflows/hosted-sync.yml`: 소스 확인, 동기화, 회귀 검사
- 루트 Python·static 파일: 기존 PC 실행 버전

소스는 이 저장소에서 계속 관리합니다. GitHub에 저장한 코드가 운영 사이트에 자동 배포되지는 않으며, 검증한 버전을 Sites에 게시합니다.

## 개인정보와 접속

학생 DB·원본 엑셀·생년월일·접속 비밀번호·비밀 환경값·백업은 GitHub에 저장하지 않습니다. 실제 자료는 별도 비공개 데이터베이스에 보관합니다. 공유 비밀번호는 서버 비밀 환경값에만 저장합니다. 접속은 4시간 후 만료되며 반복 입력을 제한합니다.

관리자는 전체 입력과 권한 관리를 할 수 있습니다. 개별 교사 계정을 추가로 사용할 경우 관리 → 교사 권한·공유에서 이메일·자료학년도·담당 반을 지정합니다.
