# 2027 수시진학관리

학생별 지원, 수험번호, 내신, 전형 일정, 합불 현황을 관리하는 비공개 웹앱입니다.

**웹앱 접속:** https://ieum-admissions-2027-kkw.awakewand22.chatgpt.site

사이트에 초대되고 앱 권한이 등록된 계정만 이용할 수 있습니다. GitHub 저장소를 공유하는 것과 학생 자료의 조회 권한을 주는 것은 별개입니다.

## 구성

- `hosted/`: 현재 온라인 운영 버전의 전체 소스. 자세한 사항은 `hosted/README.md` 참고.
- 루트의 Python 파일과 `static/`: PC에서 사용하는 기존 호환 버전.
- `.github/workflows/`: 소스 검사, 가상 자료 테스트, 운영 소스 동기화.

GitHub에는 **학생 DB·엑셀·생년월일·비밀번호·운영 비밀값·백업을 저장하지 않습니다.** 실제 자료는 별도 비공개 데이터베이스에서 관리합니다.

## 업데이트

운영 소스 변경은 브랜치와 검토를 거쳐 관리합니다. GitHub 자동 검사는 가상 자료만 사용합니다. 소스를 GitHub에 반영해도 운영 서버에 자동 배포되지는 않습니다. 검증 후 별도의 Sites 게시 절차로 운영 버전에 반영합니다.

## 공유

웹앱의 공유·권한 메뉴에서 이메일과 담당 반을 등록하고 사이트 접속 초대를 완료합니다. 담임은 담당 반 조회만 가능합니다. 앱 권한 관리는 소유자만 수행합니다.

개발자가 소스를 함께 수정하려면 GitHub 협업 권한을 별도로 부여해야 합니다. 초대할 사람의 이메일과 담당 반, 필요한 GitHub 아이디를 알려 주세요.
