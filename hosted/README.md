운영 주소: https://ieum-admissions-2027-kkw.bboykw.chatgpt.site

표시 이름은 2027 수시진학관리입니다. 기존 이용자의 주소를 보존하기 위해 URL은 유지합니다.

## 소스와 자료

이 폴더에는 실행 코드, 화면, 스키마와 마이그레이션만 저장합니다. 실제 학생·지원 자료, 비밀번호, 비밀 환경값, 로컬 데이터베이스와 백업은 GitHub에 올리지 않습니다. 운영 자료는 별도 비공개 D1에 보존됩니다. `.dev.vars`, `.env*`, `.wrangler`, `node_modules`, `dist`는 제외합니다.

## 실행 및 검증

Node 22.13 이상과 npm을 사용합니다. `npm ci` 후 `npm run dev`로 개발 서버를 실행합니다. 최초 설정은 Sites의 프로젝트 설정 도구를 사용합니다. 마이그레이션은 `npm run db:generate`로 생성하고, 기존 적용 이력은 수정하지 않습니다.

`node --test tests/logic.test.mjs`, `node --check public/app.js`, `npx tsc --noEmit`로 검증합니다. 빌드는 `npm run build`이며, 실제 배포는 Sites 게시 절차로 진행합니다. GitHub에 코드를 저장하는 것과 운영 서버에 배포하는 것은 별도 단계입니다.

## 공유

소유자가 관리 → 교사 권한·공유 메뉴에서 이메일·권한·담당 반·자료학년도를 등록합니다. 처음 접속할 때 인증된 이메일을 사이트의 사용자 ID에 연결합니다. 접속 화면은 공개이며 별도 사이트 초대는 필요하지 않습니다. 학생 자료 API는 로그인과 앱 권한을 모두 검사합니다. 앱 권한 중지는 다음 요청부터 반영됩니다.

담임은 지정 학년도 재학생의 담당 반만 조회하며 생년월일·원본·변경·권한 관리는 허용되지 않습니다. 관리자에게는 전체 학생 조회와 입력 권한이 있으며, 다른 사람의 권한 설정은 소유자만 수행합니다.

## 데이터 해석

지원 수는 원본 대조 전 잠정 집계입니다. 미입력·미발표·불합격을 구분합니다. 출처가 다른 내신을 임의로 덮어쓰거나 캠퍼스 차이를 무시해 병합하지 않습니다. 원본과 변경 이력을 보존하며 수정·병합에 버전 검사를 적용합니다.

## 공유 비밀번호 접속

교사는 접속 비밀번호로 전체 지원 현황을 조회할 수 있습니다. 서버 비밀 환경값 `VIEW_PASSWORD`에 설정하며 소스에는 저장하지 않습니다. 4시간 만료 서명 쿠키와 15분간 IP별 20회·전체 200회 시도 제한을 적용합니다. 공유 접속은 수정·권한관리·원본·생년월일 조회가 금지됩니다. 관리자 입력은 기존 ChatGPT 계정을 유지합니다. 비밀번호 변경 후 재게시하면 이전 공유 세션도 무효화됩니다.
